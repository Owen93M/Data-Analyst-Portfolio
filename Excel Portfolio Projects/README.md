# Excel Projects

These projects were combined between independent learning through various YouTube tutorials from [Alex The Analyst](https://www.youtube.com/@AlexTheAnalyst) with different types of data, and an online course for L2 Data Analytics through Code Nation.
In the projects I developed the skills that helped me clean all the data, create Pivot Tables to manipulate the data and then create charts to visualise the data. 
I then put all the charts together and into an interactive dashboard, that was easily readable to all audiences.

- **Tools Used**:
  - Pivot Tables
  - LOOKUP (V/H)
  - Charts
  - Slicers
