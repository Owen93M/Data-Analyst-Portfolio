# Python / Football Analysis Projects 

The projects were used to create a Portfolio and present any one of them to a panel of experts in the field through an online course by [Future Coders Club](https://www.skool.com/future-coders-club/about).
The Projects taught me how to explore, clean and manipulate data, create and merge tables. Along with creating various styles of charts from simple bar, line and pie charts, to heatmaps and radar charts to offer more visual understanding of insights found through exploration and specified questions.


* Tools Used
  * Pandas
  * CSV
  * NumPy
  * Matplotlib
