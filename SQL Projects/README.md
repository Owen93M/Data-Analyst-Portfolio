# SQL

The SQL Project was created using a Tutorial from [Alex The Analyst](https://www.youtube.com/watch?v=OT1RErkfLNQ), which taught the basics, through to more advanced techniques and culminated in 2 projects. One based around  Data Cleaning and the other is and Exploratory Data Analysis **(EDA)** project.
In this project I cleaned any wrong data, manipulated the data through such methods as **Queries** and **Joins** to find what was required and then created a presentation from it.
I also have an understanding of how to **create a new table**, **enter data into the table**, **update and delete the table**.

- Tools Used
  - SELECT 
  - GROUP BY
  -	WHERE
  -	LIMIT
  -	JOINS
  -	ALIAS
  -	WITH
  -	CTE
  -	TEMP TABLES
